# Outfit Lite

Outfit Lite is a simplified fashion try-on web application.

## Project Description

Users can explore clothing products, view product details,
and create outfits using a virtual avatar.

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- Pytest
- Docker
- GitHub Actions
- Render

## Development Workflow

The project uses feature branches and pull requests.

Development in progress.
